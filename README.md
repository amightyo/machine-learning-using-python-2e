# Machine Learning Using Python, Second Edition

**Foundations, Algorithms, Applications, and Reproducible Research**

This repository contains the source for the Second Edition of *Machine Learning Using Python*, an open and reproducible textbook developed with Quarto and Python.

## About the Book

The book is designed for data enthusiasts, analysts, students, researchers, and professionals who want to move beyond simply fitting machine learning models toward understanding how algorithms work, how models should be evaluated, and how machine learning can be applied responsibly to meaningful real-world problems.

The Second Edition emphasizes conceptual and mathematical foundations, reproducible Python workflows, supervised and unsupervised learning, neural networks, NLP, generative AI, model evaluation, explainability, fairness, responsible machine learning, health and education applications, hands-on practice, and research extensions.
