4  From Research Question to Machine Learning Problem

4.1 Learning Objectives

  • Translate substantive questions into well-defined ML tasks.
  • Define units of analysis, targets, features, and prediction horizons.
  • Distinguish predictive, inferential, descriptive, and causal questions.
  • Develop defensible baseline and evaluation strategies.
  • Identify leakage and target-definition problems before modeling.

4.2 Why This Matters

Many failed ML projects begin with an algorithm instead of a clearly defined problem.

4.3 Real-World Problem

A university asks: “Which students will struggle?” Convert this vague request into a precise, ethical, and evaluable machine learning problem.

4.8 Common Mistakes

  • Predicting information that is already known at prediction time.
  • Using future information as a feature.
  • Defining targets inconsistently.
  • Optimizing a metric unrelated to the actual decision.

4.9 Knowledge Check

  1. What is the unit of analysis?
  2. What is a prediction horizon?
  3. How can target leakage occur?
  4. Why should a baseline be established before complex modeling?

4.11 Professor’s Challenge

A feature dramatically improves performance but is only observed after the outcome occurs. Can it be used?

4.12 Research Extension

Develop a research question and contribution statement around the case study.

4.13 Reproducibility Check

Version the problem statement and document target, features, exclusions, timing, and evaluation plan.

4.14 Key Takeaways

  • Problem formulation precedes algorithm selection.
  • Time and data availability determine whether a prediction is legitimate.
  • Evaluation metrics must reflect the decision context.
