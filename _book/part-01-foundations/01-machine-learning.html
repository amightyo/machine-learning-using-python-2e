1  Machine Learning in the Age of Data and AI

1.1 Learning Objectives

  • Define machine learning and distinguish it from related areas of artificial intelligence.
  • Differentiate supervised, unsupervised, semi-supervised, and reinforcement learning.
  • Distinguish prediction, explanation, inference, and decision-making objectives.
  • Describe the end-to-end machine learning lifecycle.
  • Identify opportunities and limitations of machine learning in real-world settings.

1.2 Why This Matters

Machine learning now supports decisions across health, education, finance, science, business, and public policy. Effective data scientists need more than the ability to call an algorithm: they must understand what problem is being solved, what evidence a model provides, and when machine learning is inappropriate.

1.3 Real-World Problem

Consider a university seeking to identify students who may need additional academic support. What can a predictive model legitimately tell decision-makers, and what can it not tell them?

1.8 Researcher Track

Focus additionally on research questions, generalization, benchmarking, uncertainty, reproducibility, and scientific contribution.

1.9 Hands-On Practice

Classify a collection of real-world problems by learning type, target, unit of analysis, and appropriate evaluation strategy.

1.10 Common Mistakes

  • Treating every data problem as a machine learning problem.
  • Confusing prediction with causation.
  • Choosing an algorithm before defining the problem.
  • Reporting accuracy without considering the decision context.

1.11 Knowledge Check

  1. How does supervised learning differ from unsupervised learning?
  2. What is generalization?
  3. Why does prediction not establish causation?
  4. When might a simple model be preferable to a complex model?

1.12 Real-World Case Study

1.12.1 Student Success as a Machine Learning Problem

Formulate a student-success problem using a public education dataset and identify the target, predictors, unit of analysis, risks, and evaluation strategy.

1.13 Professor’s Challenge

A model predicts student non-retention with 90% accuracy. Is that enough evidence to deploy it? Explain what else you would need to know.

1.14 Research Extension

Identify a substantive gap that could transform the case study from a classroom prediction exercise into a research contribution.

1.15 Reproducibility Check

Document the problem definition, data source, target definition, assumptions, and intended use before modeling begins.

1.16 Key Takeaways

  • Machine learning is a problem-solving framework, not merely a collection of algorithms.
  • Prediction, inference, and causation answer different questions.
  • Generalization to unseen data is central to machine learning.
  • Responsible modeling begins before code is written.
