# Contributing

Thank you for your interest in improving *Machine Learning Using Python, Second Edition*.

During active development:

1. Open an issue describing an error, improvement, or reproducibility problem.
2. Identify the chapter or file involved.
3. Include enough detail to reproduce the issue.
4. For code issues, include your Python and package versions when relevant.

Substantial content contributions should be discussed before a pull request is prepared.

All contributions must respect the licenses and attribution requirements of third-party materials.
