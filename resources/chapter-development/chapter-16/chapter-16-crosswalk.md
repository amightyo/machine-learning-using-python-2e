# Chapter 16 Crosswalk

Technical progression: generalization claim → classification/regression metrics → discrimination → calibration → decision thresholds → cross-validation → repeated CV → nested CV → uncertainty → paired comparison → temporal/external validation → distribution shift → subgroup evaluation → clustered-data splitting → adaptive benchmark overfitting.

Connections: Chapter 4 problem framing; Chapter 5 leakage; Chapters 6–15 model-specific evaluation; Chapter 17 responsibility and deployment consequences; Chapter 18 reproducible evaluation.

Philosophical theme: bounded evidence. Credit a model only for claims supported by its evaluation design.
