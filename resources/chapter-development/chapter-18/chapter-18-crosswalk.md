# Chapter 18 Crosswalk

Technical progression:

research question → provenance → project structure → randomness → environment → leakage-safe pipeline → experiment configuration → Git → remote repository → Quarto → artifact serialization → automated workflows → tests → provenance → archival release → DOI → restricted-data reproducibility → robustness → replication → research artifact.

Connections:
- Chapter 5: preprocessing and leakage;
- Chapter 16: evaluation, uncertainty, external validation;
- Chapter 17: privacy, governance, documentation, responsible sharing;
- Entire book: turns the modeling workflow into a citable scientific artifact.

Philosophical theme: reproducibility is infrastructure for scientific self-correction. The objective is not to preserve the appearance of certainty but to preserve enough evidence for others to inspect, challenge, reproduce, and extend the work.
