# Chapter 2 Research and Editorial Notes

- Official Python documentation supports isolated `venv` environments and requirements-based package recreation.
- Current Quarto documentation supports executable Python blocks and reproducible computational documents.

- Missing-data concepts are introduced here; pipeline-safe imputation belongs in Chapter 5.
- Avoid manual alteration of research source data.
- Do not turn this chapter into a generic Python manual.
