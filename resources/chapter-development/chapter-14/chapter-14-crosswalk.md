# Chapter 14 Crosswalk

## Technical progression

language → tokens → document-term matrices → bag of words → n-grams → TF-IDF → cosine similarity → leakage-safe classification → lexical interpretation → distributed embeddings → contextual embeddings → self-attention → transformers.
